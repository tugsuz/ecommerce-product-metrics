Put `events.csv` from the Retailrocket dataset here
(https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset).
The data is not part of this repository. Its licence is CC BY-NC-SA 4.0.

To try the code without the data: `python make_synthetic.py` writes
`data/events_synthetic.csv`, then `python run_all.py data/events_synthetic.csv`.
